Pass 2 Cleans up the "Asymmetric Unit" using a strict fractional threshold ($10^{-4}$).

Pass 3 (CRITICAL) This is where the Burai magic happens. For every symmetry operator:

  1. Apply the linear symmetry operation.
  2. Wrap the result back into the cell (PBC Wrapping).
  3. Convert the result to **Cartesian Ångströms**.
  4. Perform a **Euclidean distance check** ($0.001$ Å).

By comparing in Cartesian space rather than fractional, we avoid the "Floating Point Drift" error that plagues naive CIF parsers.
