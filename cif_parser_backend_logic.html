01. Lattice Matrix Generation

const cosg = Math.cos(gamma), sing = Math.sin(gamma);
const cosb = Math.cos(beta);
const cosa = Math.cos(alpha);
const vol  = Math.sqrt(1 - cosa*cosa - cosb*cosb - cosg*cosg 
             + 2*cosa*cosb*cosg);
const mat  = [
  [a, b*cosg, c*cosb],
  [0, b*sing, c*(cosa - cosb*cosg)/sing],
  [0, 0,      c*vol/sing],
];

The Physics of Real-Space

This code constructs the conversion matrix $\mathbf{M}$ that maps unitless fractional sites to physical coordinates in Ångströms.

\[ \mathbf{r}_{cart} = \mathbf{M} \cdot \mathbf{r}_{fract} \]

The matrix is an upper-triangular representation of the lattice vectors. The vol variable calculates the fractional volume of the unit cell, ensuring that even non-orthogonal systems (like Hexagonal or Triclinic) are handled with exact trigonometric precision.

Symmetry as Linear Algebra

Instead of risky string evaluation, the code treats symmetry operators as linear transformations. The regex parses "x+1/2" into numeric coefficients.

\[ \begin{pmatrix} \xi' \\ \eta' \\ \zeta' \end{pmatrix} = \begin{pmatrix} S_{xx} & S_{xy} & S_{xz} \\ S_{yx} & S_{yy} & S_{yz} \\ S_{zx} & S_{zy} & S_{zz} \end{pmatrix} \begin{pmatrix} \xi \\ \eta \\ \zeta \end{pmatrix} + \mathbf{\tau} \]

By returning an object with xC, yC, zC, we convert a human-readable string into a set of 3D vectors that can be processed instantly by the CPU.

Mitigating Floating Point Drift

The most common error in CIF parsing occurs at periodic boundaries (e.g. $0.9999$ and $0.0001$). A simple equality test fails here.

This code implements the Burai software standard: it converts atoms to Cartesian Ångströms before comparison and uses a squared distance threshold.

\[ R^2 = \Delta x^2 + \Delta y^2 + \Delta z^2 < (10^{-3})^2 \]

This ensures that "Ghost Atoms" created by symmetry operations are perfectly merged into a single physical site.
